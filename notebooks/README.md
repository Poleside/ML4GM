# Notebooks

The notebooks in `tutorials/` use the supported `ml4gm` package API and are the
maintained examples for this repository.

The notebooks in `legacy/` preserve the historical research workflow and its
embedded outputs byte-for-byte. They may contain machine-specific paths and are
not the supported quickstart.

For current installation, data preparation, and execution instructions, follow
the root `README.md` and the configuration files in `configs/`.
