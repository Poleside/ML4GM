# Roadmap

The roadmap describes intent rather than a promise of dates or results.

## 0.1.0 — reproducible preview

- Package the supported evaluation pipeline and CPU synthetic quickstart.
- Provide leakage-aware LOYO, spatial, and strict block validation.
- Preserve legacy notebooks separately from the supported tutorial.
- Establish open-source governance, data provenance, and CI checks.

## 0.2.0 — verified full benchmark

- Record verified acquisition and redistribution decisions for every source.
- Run the documented full-data protocol from immutable manifests.
- Publish environment, configuration, fold-level results, and limitations.
- Add comparison reports only after independent scientific review.

## 0.3.0 — contributor model plugins

- Define a stable external model interface.
- Add plugin discovery and compatibility tests.
- Document compute budgets and deterministic reference fixtures.
- Expand contributor review and release responsibilities.
